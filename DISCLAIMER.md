# Disclaimer

This repository is an educational and interoperability research project. It studies publicly deployed smart contracts by analysing their public bytecode, in the same spirit as the lawful-use terms of the REA tool it relies on.

- Not affiliated with, endorsed by, or sponsored by Uniswap Labs or any other party.
- Not audited. Do not deploy these contracts to a public network or use them with real funds.
- The web demo uses simulated tokens and makes read-only calls to a public Ethereum RPC. It never requests a wallet connection or a signature.
